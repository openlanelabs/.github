# Support

## Community support (free)

- 🐛 [Bug tracker](https://github.com/openlanelabs/openlane/issues) — check existing issues first
- 💬 [Discussions](https://github.com/orgs/openlanelabs/discussions) — questions, ideas, help
- 📚 [Documentation](https://github.com/openlanelabs/openlane/tree/main/docs) — the spec + ADRs

## Response expectations

We're a small team shipping a big product. We prioritize in this order:

1. Security reports (see SECURITY.md)
2. Bugs affecting data integrity or the customer portal
3. Everything else — first-in, first-out, typically within a week

## Commercial support

Self-hosting OpenLane and need guaranteed response times, migration help, or a private Slack channel? Enterprise subscriptions include SSO/SCIM, audit retention, EU data residency, and support SLAs.

## Reporting a vulnerability

See [SECURITY.md](/SECURITY.md) — never open a public issue for security reports.
