## OpenLane Labs

<div align="center">

**The open-source system of execution for post-sale delivery.**

Sales got Salesforce. Marketing got HubSpot. Post-sale got spreadsheets + Slack + hope.

OpenLane is a self-hostable, AI-native **Professional Services Automation (PSA)** platform — projects, resources, time, money, and a customer portal people actually use.

*Track nothing. Execute everything.*

</div>

---

### What we're building

| Pillar | What it does |
|---|---|
| **Projects & Playbooks** | Versioned templates, phases, tasks, dependencies, Gantt |
| **Customer Portal** | Magic-link access — no logins, no friction, 3-click tasks |
| **Resources & Capacity** | Skills matrix, utilization heatmaps, hiring forecast |
| **Time & Money** | Timesheets, rate cards, budgets, invoicing, margin truth |
| **Open Nitro** | Agentic layer — Doc, Migration, Resourcing & Governance agents with human approval gates |
| **Integrations** | Salesforce, HubSpot, Jira, Slack, Zapier + REST API, webhooks, MCP |

### Stack

`Go 1.22` · `Chi` · `Postgres 16 + RLS` · `River` · `Next.js 14` · `Tailwind` · `shadcn/ui` · `Docker`

### Principles

1. **API-first** — every UI action hits the same public API.
2. **Boring security, magical portal** — RLS everywhere, magic links for customers.
3. **Agents execute, humans approve** — no AI writes without a gate.
4. **Open by default** — AGPL core, no lock-in, full export anytime.
